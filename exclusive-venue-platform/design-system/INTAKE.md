# Design System Intake — Two-Tier Gate

Tier 1 — PROVISIONAL (active from day 1):
  tokens.provisional.css (neutral palette, system fonts, 4px spacing scale)
  authorizes INTERNAL/ADMIN surfaces only: staff app, landlord portal,
  vendor dashboard. Ship functional; a reskin pass task is logged for
  when the real kit lands.

Tier 2 — ACCEPTED (flips when brand kit is ingested):
  Accepted: no   ← flip to yes after /design-system ingests the real kit
  Required BEFORE any work on CLIENT-FACING surfaces:
  proposal template (PDF + link page), public Concierge page,
  public vendor directory.

Rationale: the brand kit is a client dependency (due Jul 17). A single hard
gate would let a late brand kit stall Week-2 internal builds. The luxury bar
applies where the client's clients look.
